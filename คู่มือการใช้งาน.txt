1. ภาพรวมของโปรแกรม
--------------------------------------------------------------------------------
โปรแกรมนี้ใช้จัดการข้อมูล "หัวชาร์จรถยนต์ไฟฟ้า" ของสถานีชาร์จ EV ผ่านเมนูบน
เทอร์มินัล โดยทำได้ดังนี้

  - เพิ่ม แก้ไข ลบ และดูข้อมูลหัวชาร์จ (CRUD)
  - ทำเครื่องหมายว่าหัวชาร์จ "ถูกจอง/กำลังชาร์จ" หรือ "ว่าง"
  - บันทึกประวัติการทำรายการทุกครั้งลงไฟล์ log
  - สร้างรายงานสรุปเป็นไฟล์ข้อความ (report.txt)

ข้อมูลทั้งหมดเก็บในไฟล์ไบนารี 3 ไฟล์ (ใช้โมดูล struct ของ Python) แบบระเบียน
ความยาวคงที่ (fixed-length) และ endianness เป็น Little-Endian


--------------------------------------------------------------------------------
2. สิ่งที่ต้องมีก่อนใช้งาน
--------------------------------------------------------------------------------
  - Python 3.10 ขึ้นไป (ทดสอบแล้วบน Python 3.13)
  - ไม่ต้องติดตั้งไลบรารีเพิ่มเติม (ใช้เฉพาะ Python Standard Library)
  - เทอร์มินัลที่รองรับ UTF-8 เพื่อแสดงผลภาษาไทยได้ถูกต้อง

  หมายเหตุสำหรับ Windows:
    ถ้าภาษาไทยแสดงผลเป็นตัวอักษรแปลก ๆ ให้พิมพ์คำสั่งนี้ก่อนรันโปรแกรม
        chcp 65001
    (ไฟล์ทั้งหมดบันทึกเป็น UTF-8 อยู่แล้ว ปัญหาอยู่ที่การแสดงผลของหน้าจอเท่านั้น)


--------------------------------------------------------------------------------
3. วิธีเริ่มต้นโปรแกรม
--------------------------------------------------------------------------------
เปิดเทอร์มินัลแล้วเข้าไปยังโฟลเดอร์โปรเจกต์ (Project-Python-EV) จากนั้น

  กรณีเริ่มใช้งานครั้งแรกและต้องการข้อมูลตัวอย่าง 55 ระเบียน:
        python main.py --seed

  กรณีต้องการเริ่มจากฐานข้อมูลว่างเปล่า:
        python main.py

เมื่อเปิดโปรแกรม จะแสดงข้อมูลสรุปของระบบ เช่น สเปกไฟล์ โฟลเดอร์ข้อมูล เขตเวลา
(+07:00) และจำนวนระเบียนในปัจจุบัน แล้วจึงเข้าสู่เมนูหลัก


--------------------------------------------------------------------------------
4. ตัวเลือกบรรทัดคำสั่ง (Command-line options)
--------------------------------------------------------------------------------
  คำสั่ง                                  ความหมาย
  --------------------------------------  ------------------------------------------
  python main.py                          เข้าเมนูหลัก
  python main.py --seed                   สร้างข้อมูลตัวอย่าง 55 ระเบียน แล้วเข้าเมนู
  python main.py --report-only            สร้างรายงาน .txt จากข้อมูลปัจจุบัน แล้วออก
  python main.py --rebuild-index          สร้าง index.dat ใหม่จาก charge_points.log
  python main.py --reset                  เริ่มระบบใหม่แบบว่างเปล่า (ล้างข้อมูลเดิม)
  python main.py --data-dir <โฟลเดอร์>    เก็บ/อ่านไฟล์ข้อมูลในโฟลเดอร์ที่ระบุ
  python main.py --spec                   แสดงสเปกระเบียนของไฟล์ไบนารีทั้ง 3 ไฟล์
  python seed_data.py --force             สร้างข้อมูลตัวอย่างโดยตรง

  ตัวอย่างการใช้โฟลเดอร์อื่น (Windows):
        python main.py --data-dir D:\my-ev-data

  คำเตือน: --reset จะเริ่มระบบใหม่ ข้อมูลเดิมจะหายไป ควรสำรองไฟล์ก่อนใช้

5. เมนูหลัก
--------------------------------------------------------------------------------
  1) Add (เพิ่ม)
  2) Update (แก้ไข)
  3) Delete (ลบแบบ soft delete)
  4) View (ดู)
  5) Generate Report (.txt)
  0) Exit (ออกจากโปรแกรม)

วิธีใช้: พิมพ์ตัวเลขของเมนูที่ต้องการ (0-5) แล้วกด Enter
ถ้าพิมพ์ผิด โปรแกรมจะแจ้งเตือนและให้เลือกใหม่ ไม่หยุดทำงาน


--------------------------------------------------------------------------------
6. วิธีใช้งานแต่ละเมนู
--------------------------------------------------------------------------------

6.1 Add (เพิ่มหัวชาร์จ)
~~~~~~~~~~~~~~~~~~~~~~~
เลือกเมนู 1 แล้วกรอกข้อมูลตามลำดับ

    Point ID        รหัสหัวชาร์จ เป็นจำนวนเต็มบวก ห้ามซ้ำกับหัวที่ยังไม่ถูกลบ
    Station Code    รหัสสถานี รูปแบบ EVS-NNNN เช่น EVS-0001
    Location        ที่ตั้ง เช่น ชื่อห้าง ชั้น จุดจอด (ดูข้อควรระวังด้านล่าง)
    Plug Type       เลือกหมายเลข 1-4  (1=Type2, 2=CCS2, 3=CHAdeMO, 4=GB-T)
    Power (kW)      กำลังไฟสูงสุด ต้องมากกว่า 0
    Price (THB/kWh) ราคาต่อหน่วย ต้องมากกว่า 0
    Status          1 = Active (ใช้งานได้), 0 = Inactive (ปิดซ่อมบำรุง)
    Booked          1 = มีการจอง/กำลังชาร์จ, 0 = ว่าง

  สิ่งที่โปรแกรมทำให้อัตโนมัติ:
    - ตั้งเวลา created_at และ updated_at เป็นเวลาปัจจุบัน
    - ถ้ามีช่องที่เคยถูกลบ (soft delete) อยู่ จะนำช่องนั้นกลับมาใช้ซ้ำ
      ถ้าไม่มีช่องว่างจึงเพิ่มต่อท้ายไฟล์
    - บันทึก log (ADD) และอัปเดตดัชนี (index.dat)

  ข้อควรระวังเรื่อง Location:
    ฟิลด์นี้เก็บได้สูงสุด 30 ไบต์ (UTF-8) ตัวอักษรไทย 1 ตัวใช้ 3 ไบต์
    จึงรับภาษาไทยได้ประมาณ 10 ตัวอักษร ถ้าพิมพ์ยาวเกิน โปรแกรมจะเตือนก่อน
    แล้วตัดให้พอดีโดยไม่ตัดกลางตัวอักษร


6.2 Update (แก้ไขข้อมูล / จอง / ปล่อยหัวชาร์จ)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
เลือกเมนู 2 แล้วกรอก Point ID ของหัวชาร์จที่ต้องการแก้ไข

  - แก้ไขได้ทุกฟิลด์ ยกเว้น point_id และ created_at
  - ใช้เมนูนี้เปลี่ยนสถานะ Booked เพื่อ "จอง" (1) หรือ "ปล่อย" (0) หัวชาร์จ
  - ใช้เมนูนี้เปลี่ยน Status เพื่อ เปิดใช้งาน (1) หรือ ปิดซ่อมบำรุง (0)
  - โปรแกรมอัปเดต updated_at อัตโนมัติ
  - บันทึก log (UPDATE) และอัปเดตดัชนี
  - ถ้าไม่พบ Point ID โปรแกรมจะแจ้งว่าไม่พบ และกลับสู่เมนู


6.3 Delete (ลบ)
~~~~~~~~~~~~~~~
เลือกเมนู 3 แล้วกรอก Point ID

  - เป็นการลบแบบ soft delete คือตั้ง is_deleted = 1 ไม่ได้ลบไบต์ออกจากไฟล์จริง
  - โปรแกรมจะถามยืนยัน (y/n) ก่อนลบทุกครั้ง
  - ห้ามลบหัวชาร์จที่ถูกจองอยู่ (Booked = 1)
    ต้องไปเมนู Update เพื่อปล่อยหัวชาร์จ (Booked = 0) ก่อน จึงจะลบได้
  - บันทึก log (DELETE) และอัปเดตดัชนี
  - ช่องที่ถูกลบจะถูกนำกลับมาใช้ซ้ำเมื่อ Add รายการใหม่


6.4 View (ดูข้อมูล)
~~~~~~~~~~~~~~~~~~~
เลือกเมนู 4 จะมีเมนูย่อย

  4.1 ดูรายการเดียว
      กรอก Point ID เพื่อดูรายละเอียดทุกฟิลด์ พร้อมประวัติล่าสุดของหัวชาร์จนั้น
      (โปรแกรมอ่านผ่าน index.dat จึงไม่ต้องไล่อ่านทั้งไฟล์ log)
      การดูรายการเดียวจะถูกบันทึกลง log เป็น VIEW ด้วย

  4.2 ดูทั้งหมด
      แสดงทุกระเบียนเป็นตาราง รวมระเบียนที่ถูกลบแล้ว (Status = Deleted)

  4.3 ดูแบบกรอง
      กรองตาม station_code / plug_type / status / is_booked
      (ไม่แสดงระเบียนที่ถูกลบ)

  4.4 สถิติโดยสรุป
      แสดงจำนวนหัวชาร์จ สถานะการจอง สถิติราคา ฯลฯ
      (ไม่นับระเบียนที่ถูกลบ)


6.5 Generate Report (สร้างรายงาน)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
เลือกเมนู 5 โปรแกรมจะสร้างไฟล์ report.txt จากข้อมูลล่าสุด
(รายละเอียดเนื้อหาดูหัวข้อ 9)


6.0 Exit (ออกจากโปรแกรม)
~~~~~~~~~~~~~~~~~~~~~~~~
เลือกเมนู 0 โปรแกรมจะ

  - สร้าง report.txt ฉบับสุดท้ายให้อัตโนมัติ
  - flush ข้อมูลและเรียก os.fsync เพื่อให้เขียนลงดิสก์ครบถ้วน
  - แสดงขนาดไฟล์ข้อมูลทั้ง 3 ไฟล์ แล้วจบการทำงาน

  ควรออกด้วยเมนู 0 เสมอ เพื่อความปลอดภัยของข้อมูล
  (ถ้ากด Ctrl+C หรือปิด stdin โปรแกรมจะจัดการออกอย่างปลอดภัยให้เช่นกัน)

7. กติกาการกรอกข้อมูล (การตรวจสอบอินพุต)
--------------------------------------------------------------------------------
ถ้ากรอกผิด โปรแกรมจะแจ้งเหตุผลและให้กรอกใหม่ ไม่หยุดทำงาน

  ฟิลด์            กติกา
  ---------------  -------------------------------------------------------------
  point_id         จำนวนเต็มบวก (1, 2, 3, ...) ห้ามเป็น 0 ติดลบ หรือตัวอักษร
  station_code     ต้องเป็นรูปแบบ EVS-NNNN (N คือตัวเลข 4 หลัก)
                   ถูก: EVS-0001   ผิด: EVS-001, EVS-00001, ABC-0001
  location         ห้ามว่าง และไม่เกิน 30 ไบต์ (UTF-8) ถ้าเกินจะเตือนก่อนตัด
  plug_type        เลือกได้เฉพาะ Type2 / CCS2 / CHAdeMO / GB-T
  power_kw         ตัวเลขที่มากกว่า 0
  price_per_kwh    ตัวเลขที่มากกว่า 0
  status           0 หรือ 1 เท่านั้น
  is_booked        0 หรือ 1 เท่านั้น

หมายเหตุ: station_code ซ้ำกันได้ (หลายหัวชาร์จอยู่สถานีเดียวกันได้)
          แต่ point_id ห้ามซ้ำ


--------------------------------------------------------------------------------
8. ไฟล์ที่โปรแกรมสร้างขึ้น
--------------------------------------------------------------------------------
ไฟล์ทั้งหมดอยู่ในโฟลเดอร์ข้อมูล (ค่าเริ่มต้นคือโฟลเดอร์โปรเจกต์
หรือโฟลเดอร์ที่ระบุด้วย --data-dir)

  ไฟล์                  ชนิด       ขนาด/ระเบียน  หน้าที่
  --------------------  ---------  ------------  --------------------------------
  charge_points.dat     ไบนารี     82 ไบต์       ข้อมูลหัวชาร์จ (ไฟล์หลัก)
  charge_points.log     ไบนารี     24 ไบต์       ประวัติการทำรายการ (audit log)
  index.dat             ไบนารี      8 ไบต์       ดัชนี point_id -> ลำดับใน log
  report.txt            ข้อความ    -             รายงานสรุป (UTF-8)

  คำเตือน: ไฟล์ .dat และ .log เป็นไฟล์ไบนารี ห้ามเปิดแก้ด้วยโปรแกรมแก้ไขข้อความ
           เพราะจะทำให้โครงสร้างระเบียนเสียหาย

  ความหมายของ op_code ใน log:  1=ADD  2=UPDATE  3=DELETE  4=VIEW


--------------------------------------------------------------------------------
9. การอ่านรายงาน report.txt
--------------------------------------------------------------------------------
รายงานประกอบด้วยส่วนต่าง ๆ ดังนี้

  1) ส่วนหัว       เวลาที่สร้าง (+07:00) เวอร์ชัน endianness และ encoding
  2) [Charge Points]
                   ตารางหัวชาร์จทั้งหมด (PtID, Station, Location, Plug,
                   Power(kW), Price(THB/kWh), Status, Booked)
                   Status แสดง Deleted ถ้าระเบียนถูกลบ มิฉะนั้นแสดง
                   Active หรือ Inactive
  3) Summary       Total Points   จำนวนระเบียนทั้งหมดในไฟล์
                   Active Points  จำนวนหัวที่ใช้งาน
                   Deleted Points จำนวนหัวที่ถูกลบ
                   Currently Booked  จำนวนหัวที่ถูกจอง
                   Available Now  หัวที่ว่างและพร้อมใช้
                   Free Slots     จำนวนช่องว่างที่นำกลับมาใช้ซ้ำได้
  4) Price Statistics
                   ราคาต่ำสุด / สูงสุด / เฉลี่ย (เฉพาะ Active)
  5) Points by Plug Type
                   จำนวนหัวชาร์จแยกตามชนิดหัวจ่าย (เฉพาะ Active)
  6) Recent Activity
                   5 เหตุการณ์ล่าสุดจาก charge_points.log เรียงจากใหม่ไปเก่า

ตัวอย่างค่าสรุปจากชุดข้อมูลตัวอย่าง 1001-1010:
    Active 9 / Deleted 1 / Booked 4 / Available 5
    ราคา Min 6.00 / Max 9.00 / Avg 7.36


--------------------------------------------------------------------------------
10. การซ่อมแซมไฟล์ข้อมูล
--------------------------------------------------------------------------------
โปรแกรมตรวจไฟล์ให้อัตโนมัติทุกครั้งที่เริ่มทำงาน

  กรณี 1: ขนาดไฟล์ไม่หารลงตัวด้วยขนาดระเบียน (ไฟล์ถูกตัดกลางระเบียน)
          -> โปรแกรมแจ้งเตือนและตัดส่วนเกินทิ้ง

  กรณี 2: index.dat ไม่ตรงกับ charge_points.log หรือ index.dat หาย
          -> โปรแกรมสร้างดัชนีใหม่จาก log ให้อัตโนมัติ
          หรือสั่งเองด้วยคำสั่ง
                python main.py --rebuild-index

  คำแนะนำ: สำรองไฟล์ charge_points.dat / .log / index.dat เป็นระยะ
           โดยคัดลอกไปเก็บไว้ในโฟลเดอร์อื่น

11. การรันชุดทดสอบ
--------------------------------------------------------------------------------
รันทดสอบทั้งหมด (183 เทสต์):
        python -m unittest discover -s tests -v

รันทดสอบเฉพาะโมดูล เช่น models:
        python -m unittest tests.test_models -v

เมื่อสำเร็จจะแสดงคำว่า OK ท้ายผลลัพธ์


--------------------------------------------------------------------------------
12. ปัญหาที่พบบ่อยและวิธีแก้ไข
--------------------------------------------------------------------------------
  ปัญหา: ภาษาไทยแสดงเป็นตัวอักษรแปลก ๆ บน Windows
  วิธีแก้: พิมพ์ chcp 65001 ก่อนรันโปรแกรม

  ปัญหา: Add แล้วแจ้งว่า point_id ซ้ำ
  วิธีแก้: ใช้ View 4.2 ตรวจดูรหัสที่มีอยู่ แล้วเลือก Point ID ใหม่
          (หัวที่ถูกลบแล้วไม่นับว่าซ้ำ)

  ปัญหา: ลบหัวชาร์จไม่ได้ ขึ้นว่า "กำลังถูกจองอยู่"
  วิธีแก้: ไปเมนู Update แล้วตั้ง Booked = 0 ก่อน จากนั้นจึงลบ

  ปัญหา: Location ที่เก็บถูกตัดสั้นกว่าที่พิมพ์
  วิธีแก้: เป็นไปตามสเปกฟิลด์ความยาวคงที่ 30 ไบต์ (ภาษาไทยได้ราวไม่เกิน
